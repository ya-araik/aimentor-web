# ИИ-ментор: план веб-приложения

Актуализировано **5 октября 2026 года** по [новому Swagger](contracts/aimmentor.openapi.json) с 12 операциями и проверке работающего сервера. Контракт от 24 сентября сохранён отдельно. Пометки из исходного описания не подтверждают доступность функций; объём определяется API.

Делаем одно React SPA на TypeScript/Vite с Mantine, Router и TanStack Query. Существующий API отвечает за пользователей, обучение, оценку и статистику. Наш Docker-контейнер раздаёт статику и проксирует /api. Собственный Node.js бэкенд и БД не нужны.

## Объём

- Студент: регистрация с группой, вход/выход, профиль, серия дней.
- Диалог, история, запуск/восстановление задания, ответ с question_id и результат оценки.
- Каталог по программе, прогресс по skill_id и слабые места.
- Администратор: дашборд по /administration/stats, все семь блоков статистики и выбор периода daily_activity.
- Маршруты доступны согласно role из профиля. Для teacher пока только профиль; отдельный API преподавателя не предоставлен.

Регистрация/вход, дашборд и сценарий задания проверены на сервере. **Интеграционная приёмка ещё не закрыта:** текущее задание возвращается после завершения и теряет исходный текст; история нарушает порядок; у группы 2020tt2 пустой каталог и создание задания возвращает 500. В клиенте есть ограниченные обходы восстановления и истории, необходимые серверные исправления описаны в аудите. Публичное назначение admin и HTTP upstream также требуют исправления перед выпуском.
