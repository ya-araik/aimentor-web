# Как студенту пользоваться ИИ-ментором

## Суть проекта

ИИ-ментор помогает тренировать навыки из учебной программы студента. Сервер определяет программу по учебной группе, подбирает задание под слабый навык, ведёт диалог, оценивает ответ и сохраняет прогресс и темы для повторения. Студент не создаёт навыки вручную.

Проектное описание предполагает ежедневную практику. В текущем API новое задание создаётся вручную по кнопке; автоматической ежедневной выдачи и календаря в клиенте нет.

## После регистрации

1. Войти и проверить учебную группу в «Профиле».
2. Открыть «Навыки и прогресс» → **«Каталог навыков»**: это темы учебной программы. Вкладка «Мой прогресс» сначала пуста, потому что ответов ещё не оценивали.
3. На компьютере в чате нажать **«Получить задание»** в блоке практики. На телефоне открыть кнопку **«Задание»** сверху или **«Начать практику»** в пустом диалоге, затем получить задание на отдельном экране. Прочитать текст и нажать **«Ответить в чате»**. Самостоятельно выбирать навык текущий API не позволяет. Если задача уже есть, для её замены используется кнопка «Новое задание».
4. Прочитать задачу и написать свой ответ в поле сообщения. Режим **«Ответ на задание»** включается автоматически после выдачи. В этом режиме можно отправлять решение, уточнение или просьбу о подсказке.
5. Если трудно, написать, например: «Я не понимаю, с чего начать. Дай подсказку» или «Правильно ли я понимаю, что …?». Ментор по замыслу помогает вопросами и подсказками.
6. Когда сервер завершит оценку, появятся результат и замечания. Во вкладке «Мой прогресс» появится оценённый навык и темы для повторения; затем можно получить следующее задание.

На телефоне между чатом, навыками и профилем можно переключаться через нижнюю панель. Черновик и режим сообщения сохраняются при переходах. Просмотр задания не создаёт новое; вернуться можно стрелкой, кнопкой внизу или системной кнопкой «Назад». После оценки подробности доступны по кнопке «Результат задания» в чате.

Пример задачи: сравнить экспертную систему с системой машинного обучения и объяснить, какой подход подходит для рекомендаций товаров. Ответ — собственное объяснение в чате; для уточнений можно продолжать диалог. Прикрепление файлов текущий API не поддерживает.

## Что писать без задания

Свободный чат подходит для вопросов по теме: «Объясни простыми словами, чем машинное обучение отличается от обычной программы» или «Задай мне несколько вопросов, чтобы проверить понимание нейросетей». При активном задании выбрать режим «Вопрос ментору». Примеры в пустом чате заполняют черновик; сообщение отправляется только после нажатия «Отправить».

Свободный разговор не заменяет выполнение задания: не следует ожидать, что произвольный вопрос создаст оценку навыка. Для учитываемой практики нужен выданный сервером question_id и ответ, связанный с ним.

## Известная проблема группы 2020tt2

5 октября 2026 года подтверждены пустой каталог и ошибка 500 при выдаче задания для этой группы. Поэтому основной сценарий обучения сейчас недоступен. Пустой прогресс до первой оценки нормален; пустой учебный каталог требует подготовки/проверки данных заказчиком. Причина внутренней ошибки уточняется по серверным логам.

Для другой группы, 2026ии1, проверены 27 навыков и успешная выдача. Не нужно перерегистрироваться в неподходящую группу или самостоятельно придумывать оцениваемое задание: необходимо исправить данные/обработку правильной группы. До исправления можно использовать свободный чат.

Подробности для заказчика — в [customer-api-requirements.md](customer-api-requirements.md), дополнение по группе 2020tt2.
