## Реальная интеграция

URL появился в Swagger. Отдельные тестовые student/admin созданы с разрешения пользователя. Данные доступа — только в игнорируемой .local/integration-accounts.json; каталог исключён из Docker-контекста. В локальных .env и web/.env.local настроен тестовый API; dev-моки отключены для реальной проверки.

На реальном сервере получена оценка 85 по навыку 1, task_completed=true, обновлены progress и streak=1. Дашборд доступен admin, студент получает 403. Некорректный JWT возвращает 401; limit истории вне диапазона — 422. Подробности и воспроизведение — в [отчёте](integration-2026-10-05.md).

После [восстановления Docker Desktop](environment-recovery.md) `docker compose up --build -d` успешно собрал текущий клиент. На `http://localhost:8080` через прокси проверены вход и /me обеих ролей, /skills, /progress, /streak, /chat/history, /task/current, свободный POST /chat без question_id, дашборд (admin 200, student 403), конфликт регистрации 409. Приложение оставлено работающим для просмотра.

Выполнен воспроизводимый `scripts/browser-smoke.mjs` на готовом контейнере и реальном API. Регистрация через мобильную форму дала 201 и role=student; новый студент вошёл и получил пустой диалог. Вход обеих ролей, просмотр weaknesses/серии, свободный чат с question_id=null, выход, отказ в административном маршруте студенту, смена days и реакция на реальный 401 прошли. Горизонтального переполнения на 390 px и исключений браузера не обнаружено. Отчёт и скриншоты находятся в игнорируемой `.local/browser-smoke/`; QA-доступ нового студента добавлен к локальному файлу.

Браузерная проверка выявила отсутствие перехода к новым сообщениям. Добавлено следование за последними сообщениями при открытии/отправке, с сохранением позиции при чтении старой истории. Проверка была красной до исправления и зелёной после. Длинная карточка задания теперь раскрывается по кнопке. Обновлённый контейнер пересобран, 10 тестов проходят.

## Оставшаяся работа

### Уточнение UI по просьбе пользователя

Вопросы к заказчику отложены, доработан клиентский интерфейс: строгая общая тема, задание и чат рядом на десктопе, понятный первый шаг, явные режимы сообщения, примеры вопросов без автоматической отправки, разные пустые состояния каталога и прогресса. Текст ментора отображает Markdown. Docker пересобран; прошли 17 проверок ui-review, 14 browser-smoke и 12 unit/DOM-тестов. Направление оформления — в [ui-design.md](ui-design.md). Серверные дефекты остаются отдельным условием приёмки.

Мобильный интерфейс переработан после замечаний пользователя: чат занимает весь доступный экран, задание открывается отдельным экраном с возвратом к ответу, навигация закреплена снизу. Сохраняются черновик и режим сообщения; поддержаны visualViewport и безопасные области. Прошли 33 ui-review, 14 browser-smoke и 15 unit/DOM-тестов. Новый мобильный сценарий и границы браузерной проверки описаны в ui-design.md. Docker пересобран; клиентские изменения не закрывают серверные блокеры.

6 октября административная страница переработана в аналитический дашборд: 11 визуализаций, четыре KPI и три вкладки. Добавлены Recharts, отдельная загрузка административного модуля, преобразования данных с тестами, поиск/сортировка, фильтр группы и подробности по нажатию. Прошли 22 unit/DOM-теста, 39 проверок dashboard-review и 14 browser-smoke. Docker собран и запущен. Реальный API использован только для чтения; пустые ответы и 500 проверены браузерными подменами. Адаптивность проверена на 320/390/767 px в Chromium. Обнаруженные даты вне запрошенного периода явно отмечаются в интерфейсе; новые обращения заказчику не отправлялись. Формулы и ограничения — в [admin-analytics.md](admin-analytics.md).

Добавлена вкладка «3D» с календарным рельефом активности и рельефом распределения навыков. Есть вращение/перемещение, масштаб, вид сверху, полный экран и поиск точной точки. На телефоне жесты включаются отдельно; касания одним/двумя пальцами проверены симуляцией в Chromium. Неизвестные даты остаются разрывами, единичные записи — точками, пустые данные и отсутствие WebGL обработаны. Plotly GL3D загружается только при открытии вкладки и поставляется в том же Docker-образе без CDN. Прошли 27 unit/DOM-тестов, 33 проверки three-d-review, 39 dashboard-review и 14 browser-smoke. Контейнер с финальными изменениями собран и запущен. Проверки используют существующего QA-администратора и только читают статистику; новые запросы заказчику не отправлялись. Отчёты и снимки — в `.local/three-d-review/`. Физический телефон не проверялся.

### Серверные изменения

По последнему указанию пользователя эти изменения временно отложены при подготовке поставки. Они не блокируют технический запуск контейнера; документация и сведения о дефектах сохранены для дальнейшей работы.

- Группа 2020tt2 (group_id=2): /skills возвращает пустой массив, POST /task — 500 через прокси и напрямую. Для группы 2026ии1 каталог и выдача работают. Требуется проверка данных/привязки группы и серверной обработки пустого каталога; подробности добавлены в запрос заказчику и отчёт интеграции.
- /task/current меняет исходный текст на ответ AI и возвращает завершённое задание. Клиент сохраняет исходный текст и завершённые ID в текущей вкладке; другая вкладка/устройство остаются зависимыми от исправления сервера.
- История не хронологическая. Клиент сортирует только полностью известные времена одного формата; null не сортируется по догадкам.
- В timestamp нет зоны; отображение времени требует уточнения.
- Перед публичным выпуском закрыть назначение admin/teacher через публичную регистрацию и предоставить HTTPS upstream.

Интеграционная приёмка FE-09 открыта. Goal не считается завершённым на основании ограниченных клиентских обходов. Доступ повторно запрашивать не требуется; дальнейшие запросы заказчику собраны в [customer-api-requirements.md](customer-api-requirements.md).

Блокер повторно подтверждён после всех клиентских проверок: завершённый ID всё ещё возвращается, в 13 серверных сообщениях — 6 нарушений порядка времени. Внешнее исправление API необходимо для продолжения; подробности аудита блокировки — в [completion-audit.md](completion-audit.md). Приложение остаётся запущенным на localhost:8080.
