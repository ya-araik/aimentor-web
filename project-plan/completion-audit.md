Goal не завершён. Отдельные клиентские обходы не подтверждают корректное восстановление на новой вкладке или устройстве. Повторные однотипные запросы не исправят эти дефекты. Следующий необходимый шаг — исправление владельцем API пунктов 1–3 в customer-api-requirements.md и повторная сквозная проверка. Перед публичным выпуском отдельно закрыть назначение повышенных ролей и HTTP upstream; тестовое окружение пользователь разрешил использовать в текущем виде.

## Повторная проверка блокера

После клиентских исправлений API повторно проверен через работающий Docker-прокси. `/task/current` по-прежнему возвращает подтверждённо завершённый ID `bc8419f3-6721-48c6-bab0-48b01c2b6d17`; прогресс навыка 1 остаётся 85. В массиве из 13 сообщений обнаружены 6 переходов от более позднего timestamp к более раннему. Нового контракта или ответа заказчика нет.

Одно и то же внешнее условие сохраняется три последовательных этапа Goal: первичная проверка нового API, завершение браузерной проверки и текущая повторная проверка. Клиентская работа и необходимые проверки выполнены. Серверный исходный код отсутствует, изменить его можно только через заказчика; дальнейших самостоятельных действий для закрытия приёмки сейчас нет. Основание для статуса `blocked` — необходимость исправления работающего API, а не отсутствие доступа или незавершённая клиентская сборка.

## Дополнение после обращения пользователя

В 18:07 UTC 5 октября отдельно воспроизведён новый блокер для группы 2020tt2: /skills=[], POST /task=500 напрямую и через прокси. Для другой группы задание выдаётся. Прежняя проверка не охватывала все группы; её успешные сценарии не подтверждают готовность данных этой группы. Добавлены EXT-04, запрос заказчику и воспроизводимый scripts/check-task-availability.mjs. Статус Goal остаётся blocked; после исправления требуется повторная приёмка и для группы пользователя.
