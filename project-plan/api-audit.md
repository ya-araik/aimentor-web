# Аудит Swagger от 5 октября 2026 года

Новый AIMentor.json сохранён в [актуальном контракте](contracts/aimmentor.openapi.json). Контракт от 24 сентября — в [отдельном файле](contracts/aimmentor.openapi.2026-09-24.json), первоначальный — в aimmentor.openapi.previous.json. В OpenAPI 3.1 теперь **12 операций**; генерация TypeScript-типов проходит. Проверен сервер http://ai-mentor.tw1.ru:8000 из servers. В Swagger он назван продакшном, пользователь подтвердил тестовый статус и разрешил регистрацию и AI-сценарии.

## Что добавили

| Изменение | Возможности клиента |
| --- | --- |
| GET /administration/stats?days=1..365 | Дашборд администратора: студенты, группы, средний прогресс, слабые навыки, активность и выполненные задания |
| role, current_streak, longest_streak в UserPublic | Навигация по роли, серия дней |
| GET /streak | Обновление серии |
| ProgressItem.weaknesses | Замечания по навыку |
| Типизированный assessment и task_completed | Результат оценки и сброс активного question_id |
| Однозначный порядок истории | В контракте старые сообщения сверху |
| /skills по курсу и специальности | Каталог программы студента |
| servers | Адрес API теперь предоставлен |

Из MessageItem удалён kind. Записи по заданию помечаем по question_id, который не позволяет отличить исходное задание от других реплик. UserPublic имеет новые обязательные поля; типы и моки обновлены. В оценке есть level, необязательные feedback и skill_id; шкала level не определена, клиент показывает «уровень», без придуманного балла.

## Проверка работающего сервера

- Отдельные тестовые студент и администратор зарегистрированы, вход и /me работают.
- Студент получает навыки, историю, задание, оценку. Проверенный ответ дал level=85, task_completed=true; прогресс стал 85, серия — 1.
- Дашборд доступен администратору, студент получает 403, запрос без токена — 401.
- **Публичная регистрация действительно создаёт администратора без авторизации.** В тестовом окружении это использовано с разрешения пользователя; перед публичным выпуском повышенные роли должны назначаться доверенным оператором или защищённым методом.
- **/task/current возвращает последнюю реплику AI вместо исходного текста; после завершения продолжает возвращать тот же ID.** Клиент сохраняет исходный текст и подтверждённые завершённые ID в текущей вкладке. На другом устройстве надёжного восстановления всё ещё нет.
- **История фактически нарушает хронологию:** AI-ответ стоит перед сообщением пользователя с более ранним временем. Клиент сортирует только массивы с полностью известными временами одного формата (все с зоной или все без зоны); при null или смешении форматов порядок сохраняется.
- **Группа 2020tt2 не может начать обучение:** для group_id=2 /skills возвращает [], POST /task — 500 через прокси и напрямую. Для 2026ии1 каталог содержит 27 навыков, задание выдаётся. Требуется проверка данных/привязки группы и обработка отсутствующих навыков (в Swagger предусмотрен 503); точная причина 500 без серверных логов не установлена.
- Реальные timestamp не содержат часового пояса, несмотря на format=date-time. Требуется UTC с Z или смещение.
- Период days описан только для daily_activity; UI не выдаёт остальные показатели за статистику выбранного периода.
- При проверке дашборда 6 октября ответ days=30 содержал даты 2026-09-05–2026-11-10, ответ days=7 — 2026-09-28–2026-11-10. Это не соответствует ожидаемому календарному диапазону относительно даты клиента, включая будущие даты. Причина без серверного кода не установлена. Графики сохраняют фактические записи, показывают диапазон и пометку; добавление новых запросов заказчику отложено по просьбе пользователя. Это ограничение интерпретации аналитики, не блокер сборки UI.

Разработку интерфейса можно продолжать. Полная интеграционная приёмка остаётся открытой из-за восстановления задания, истории и отсутствия рабочего учебного сценария для группы 2020tt2. Перед публичным выпуском также нужны защищённое назначение ролей и HTTPS upstream: в Swagger сейчас HTTP.

## Границы

Представлены студенческий кабинет и агрегированный административный дашборд. Роль teacher объявлена, отдельного API преподавателя нет; в клиенте ей доступен профиль. Управление пользователями, группами и навыками, архив оценок, курсор истории, календарь ежедневных заданий, документы и остальные роли не появились.

Подробности — в [отчёте проверки](integration-2026-10-05.md), оставшиеся запросы — в [требованиях заказчику](customer-api-requirements.md).
