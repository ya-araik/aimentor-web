# Проверка сервера 5 октября 2026 года

Сервер из Swagger: `http://ai-mentor.tw1.ru:8000`. Пользователь подтвердил тестовый статус и разрешил создание аккаунтов и AI-запросы. Созданы отдельные тестовые студент (ID 34) и администратор; данные доступа сохранены в игнорируемой `.local/integration-accounts.json`, исключённой из Docker-контекста. Проверка не использовала реальные аккаунты студентов и не удаляла серверные данные.

## Воспроизведение дефектов

Для задания `bc8419f3-6721-48c6-bab0-48b01c2b6d17` студент отправил два законченных текста по теме «История и эволюция искусственного интеллекта». После второго сервер вернул `task_completed: true`, уровень 85, замечания и навык 1. Следующий `/task/current` вернул тот же ID и текст ответа ментора вместо `null`.

В истории сообщения `1390_ai` и `1391_ai` стоят перед `1390_user` и `1391_user`. Времена первой пары: AI `2026-10-05T17:20:11.44412`, user `2026-10-05T17:20:05.818336`. Часовой пояс отсутствует у обоих.

Публичный `/register` с `role: admin` создал аккаунт, вошедший как admin и получивший статистику. Это подтверждённое свойство сервера, которое нужно закрыть перед публичным выпуском.

## Локальные проверки клиента

Генерация типов из нового Swagger, typecheck и production-сборка проходят; 10 автоматических тестов успешны. Они покрывают изоляцию административных маршрутов, закрытие задания по флагу и по assessment, повторное открытие экрана при неверном ответе `/task/current`, свободный чат без старого ID, нормализацию истории и ошибки HTTP-клиента.

Новый Docker-образ собран и запущен после восстановления служебных сокетов Docker Desktop. Через `http://localhost:8080/api` проверены вход и /me обеих ролей, навыки, прогресс, серия, история, текущее задание, свободный чат с question_id=null (сервер подтвердил отсутствие связи и оценки), дашборд и конфликт регистрации 409. Вложенные /chat, /dashboard, /profile возвращают HTML приложения со статусом 200. Состояние — в [implementation-status.md](implementation-status.md).

Для повторной приёмки использовать новые тестовые задания после исправления сервера: восстановить исходный текст, отправить ответ, получить оценку, перечитать `/task/current` (ожидается null), проверить историю и обновления прогресса/серии. Клиентский обход в sessionStorage не заменяет эту проверку.

## Проверка интерфейса в Chromium

На работающем Docker-контейнере выполнен `scripts/browser-smoke.mjs` с доступным пакетом Playwright. На ширинах 1440 и 390 px проверены вход студента/admin, доступ к страницам по роли, weaknesses/серия, мобильное меню и выход, смена периода дашборда, отсутствие горизонтального переполнения. Некорректный JWT проверен через настоящий `/me`: 401 очистил сеанс и вернул страницу входа. Исключений JavaScript не было.

С флагом `--exercise-chat` отправлено свободное сообщение через форму. Проверено, что запрос не содержит старого question_id, сервер отвечает успешно, после отправки видны последние сообщения. Эта последняя проверка первоначально упала; клиент исправлен и проверка прошла после пересборки Docker.

С флагом `--exercise-registration` создан один дополнительный QA-студент через мобильную форму: запрос получил 201, role=student, интерфейс предложил войти, новый аккаунт успешно вошёл и увидел пустой диалог. Доступ сохранён в том же локальном файле; повторное создание автоматически пропускается.

Снимки экранов и отчёт — в `.local/browser-smoke/`, исключённой из Git и образа. Эти результаты подтверждают клиент и интеграцию проверенных сценариев; они не закрывают описанные дефекты `/task/current` и истории.

## Дополнительная проверка группы пользователя: 2020tt2

Пользователь сообщил, что после регистрации каталог и прогресс пусты, а новое задание возвращает 500. Ранее проверенная регистрация относилась к другой группе; результат одной группы не подтверждает готовность остальных.

`node scripts/check-task-availability.mjs 2` воспроизвёл проблему 5 октября в 18:07 UTC на отдельном QA-студенте ID 38. В `/groups` ID 2 называется `7tt2`, а профиль зарегистрированного студента показывает `2020tt2`. `/skills` вернул 200 и пустой массив; `/progress` также пуст, что ожидаемо до оценки. `/task` вернул 500 с общим сообщением о внутренней ошибке через Docker-прокси и напрямую к `http://ai-mentor.tw1.ru:8000`.

Контрольный новый студент ID 36 в группе `2026ии1` получил 27 навыков и задание со статусом 200 (ID `851fe51f-fcf4-4d8c-b0f8-22a9f319c207`, проверка в 18:06 UTC). Это подтверждает зависимость наблюдаемого сбоя от группы/её данных. Не установлено, отсутствует сама матрица, неверно определяется курс/специальность или есть другая ошибка обработки; для точной причины нужны серверные логи.

Swagger уже описывает 503 при отсутствии доступных навыков.
